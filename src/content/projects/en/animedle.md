#### Project Overview
Wordle-style daily game about anime (Jikan / MyAnimeList API), built by a team of 3 in March 2026 (M2 team project). I was team lead and in charge of the frontend architecture.

#### Features
- 🎯 **Daily**, **endless** and **character** modes.
- ⚔️ Real-time multiplayer **Challenge** mode (rooms, WebSocket).
- 🛠️ Admin area: anime and character CRUD, statistics.

#### My Contribution
Front / back architecture, authentication, admin area, visual overhaul (design system, i18n, responsive).

#### Tech Stack
React, Hono, Bun, MongoDB / Mongoose, WebSockets, Better Auth, Tailwind CSS, shadcn/ui, Zustand, Vite, Docker, Biome, Vitest.
