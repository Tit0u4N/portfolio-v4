#### Project Overview
Informiento is a university project focused on designing an interactive form for collecting user needs.  
Developed as part of the IUT curriculum, it prioritizes a simple and accessible interface, ensuring  
a smooth and intuitive user experience.

#### Project Concept
The project consists of a web page where users can input their needs through a structured form.  
The emphasis is on clarity and ergonomics to facilitate efficient data entry.

#### Key Features
- 📝 **Interactive Form**: Well-structured fields for an intuitive and user-friendly experience.
- 🎨 **Clean Design**: A simple and clear interface for better readability.
- 📩 **Input Validation**: Basic controls to ensure data consistency.

#### Tech Stack
The project relies on lightweight and efficient technologies:
- 🌐 **Front-end**: *HTML* and *CSS* for a clean and accessible layout.
- 🎨 **Styling**: *CSS* for a structured and polished visual design.
- ✅ **Validation**: Native HTML attributes to ensure correct input handling.
