#### Project Overview
WC Studio is a web-based video game platform developed as part of a computer science degree by a team of three. This project imposed strict technical constraints, prohibiting the use of frameworks such as *React* or *Vue*. Instead, it relies on a minimalist and high-performance approach, using *ViteJS* with *Server-Side Rendering* and *AlpineJS* for front-end reactivity. *Tailwind CSS* was chosen for styling and layout. The project was entirely front-end, with no back-end.

#### Project Concept
WC Studio is a platform designed to host and provide access to multiple web games. As part of the project, three games were developed:
- 🎮 **Snake**: A classic game built using the *Canvas API* in JavaScript.
- 🧠 **Memory**: A memory game where players must match pairs of images.
- 🏆 **Games On Web Project**: Integration of the game developed for the *Games On Web* tournament.

#### Technology Stack
The project is built on lightweight and efficient technologies:
- ⚡ **Build & Performance**: *ViteJS* for fast and optimized development.
- 🌐 **Rendering**: *Server-Side Rendering* for better performance and SEO.
- ⚙️ **Reactivity**: *AlpineJS* for smooth and dynamic interactions.
- 🎨 **Design & Styling**: *Tailwind CSS* for a modern and clean layout.
- 🎮 **Canvas API**: Used for rendering the *Snake* game.
