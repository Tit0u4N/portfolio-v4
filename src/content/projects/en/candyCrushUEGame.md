#### Project Overview
**Candy Crush UE Game** is a simple implementation of *Candy Crush* using **HTML**, **SCSS**, and **JavaScript**, featuring a **Glassmorphism** design. This project was developed individually as part of a university course. All animations were created using **pure CSS** to ensure smooth transitions and a modern aesthetic.

#### Game Concept
The game follows the classic *Candy Crush* mechanics, where players must match identical candies to score points. With a sleek and translucent interface, the **Glassmorphism** design adds a modern and refined touch to the gaming experience.

#### Key Mechanics
- 🍬 **Match-3 Mechanic**: Align three or more candies to make them disappear and earn points.
- 🎨 **Glassmorphism Design**: A modern interface with blur and transparency effects.
- 🎞️ **Smooth Animations**: Exclusively built with **pure CSS** for seamless and interactive transitions.
- ⏳ **Level Progression**: Increasing difficulty with specific objectives to achieve.

#### Tech Stack
The project is based on a lightweight and optimized stack:
- 🌐 **Web Development**: *HTML*, *SCSS*, *JavaScript* for a responsive implementation.
- 🎨 **Styling**: *Glassmorphism*, *SCSS* for a clean and modern design.
- 🎬 **Animations**: *Pure CSS* for smooth and efficient transitions.
- ⚡ **Performance and Optimization**: Structured and lightweight code for a fluid experience.
