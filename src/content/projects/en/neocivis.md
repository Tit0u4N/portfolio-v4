#### Project Overview
Master 2 final-year project, built by a team of 4 from December 2025 to June 2026. **Néocivis** is a civic-tech platform connecting a city's citizens with their city hall. I was co-lead of the project and of the overall architecture (with a teammate), while developing the frontend on my own and driving task distribution and deadlines.

#### Features
- 📍 **Urban reports**: geolocation, photo, AI-generated description and automatic tag assignment.
- 🗺️ **City hall side**: map and table views, status tracking, version history.
- 📰 **Modules**: news (WYSIWYG editor, i18n), help forum, push notifications, customizable city page, webhooks, polls.
- 🔐 **Granular permissions** (RBAC).

#### Tech Stack
- 🧱 **Turborepo monorepo**: 2 frontend apps, serverless backend with edge functions, shared packages.
- 🖥️ **Web**: Next.js 16 (App Router), React 19, Tailwind CSS v4, shadcn/ui, Zustand.
- 📱 **Mobile**: Expo 54, React Native.
- ✅ **Quality**: strict TypeScript, Biome, Vitest, MVVM architecture.
