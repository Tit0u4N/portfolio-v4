#### Project Overview

Saexpress is an IT directory based on *Active Directory*, developed over three months by a team of four students as part of a study project at the IUT Informatique. The objective was to design an application that allows managing and searching for users from a Windows server hosting *Active Directory*.

For the demo, the actual implementation of Active Directory and the backend has been replaced with *mocks*, with only the *React* application being deployed.

#### Application Concept

The application allows users to log in and search for registered individuals in the directory through an efficient and intuitive search engine.

#### Key Features

- 🔑 **Secure Authentication**: Login system based on *JWT*.
- 🔍 **Advanced Search**: Interface for easily finding users.
- 🖥️ **Centralized Directory**: User management from *Active Directory* (mocked for the demo).

#### Technology Stack

The application is built on a robust and modern architecture:

- 🖥️ **Backend**: *Java* with *Spring* for user and authentication management.
- 🌐 **Frontend**: *React* for a responsive and fluid interface.
- 🎨 **Styling**: *SCSS* for a clean and modular design.
- 🔄 **Communication**: Secure API with *JWT* authentication.
- ⚙️ **Deployment**: Only the *React* application is online, while the backend and *Active Directory* are simulated using *mocks*.
