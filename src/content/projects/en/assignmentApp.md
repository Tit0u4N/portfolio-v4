#### Project Overview
Assignment App is a web application for managing assignments, developed solo as part of learning Angular in a Master’s program. The app allows users to create, edit, and delete assignments, while an admin interface enables the automatic generation of multiple assignments at once.

#### App Concept
Users can manage a list of assignments with full CRUD functionality. The admin interface simplifies bulk assignment creation.

#### Key Features
- 📌 **Assignment Management**: Create, edit, and delete assignments.
- ⚙️ **Admin Interface**: Automatically generate a batch of assignments.
- 📋 **Structured Display**: Filterable and organized list of assignments.

#### Tech Stack
The application is built using a modern and efficient stack:
- 🎯 **Frontend Framework**: *Angular* for a modular and scalable structure.
- 🎨 **UI & Styling**: *Tailwind CSS* and *Angular Material* for a modern, responsive interface.
- 🗄️ **Database**: *MongoDB* for flexible and efficient data storage.
