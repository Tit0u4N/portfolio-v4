#### Project Overview
Real-time multiplayer web app inspired by the Werewolf party game, deployed in production (M1 team project, team of 5, January to June 2025). I was Project Manager and team lead, contributed to the overall architecture and led frontend development.

#### Architecture
Microservices (game-engine, game-discovery, chat, gateway, game-history, admin, bot) with two interfaces: **GameUI** (React) for players and **AdminUI** (Angular) for administrators. REST, WebSockets and SSE, JWT security.

#### My Contribution
- 📋 Overall management: scoping, coordination, sprint follow-up.
- 🎮 GameUI: main page, account, lobby and discovery, game screen, history.
- ⚙️ Game Discovery service (backend) and the backend GitHub Actions pipeline.

#### Tech Stack
Spring Boot, React, Angular, Eureka, Docker / Docker Compose, GitHub Actions, SonarQube, Nginx, Maven. Polyglot databases: PostgreSQL, MongoDB, Neo4j, Redis, Cassandra.
