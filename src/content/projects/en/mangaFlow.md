#### Project Overview
**MangaFlow** is a study project developed at the IUT by a team of two. The goal was to create an e-commerce website dedicated to selling manga using **PHP** and **vanilla JavaScript**. The project is based on an **MVC** architecture in PHP and integrates **AJAX** requests to enhance user experience.  
A shopping interface and a monitoring dashboard were developed, with payment management via **Stripe** in developer mode. To populate the database, a **scraper** was created to automatically retrieve manga covers, titles, authors, and summaries.

#### Project Concept
MangaFlow offers a smooth and intuitive shopping experience for manga enthusiasts. Thanks to a back-office, administrators can manage the catalog and track sales, while users can explore a rich library and easily place orders.

#### Key Features
- 🛒 **Shopping Interface**: Smooth and intuitive navigation to browse and purchase manga.
- 📊 **Admin Dashboard**: Manage products, users, and orders.
- 🔄 **AJAX Requests**: Enhancing interactivity for a better user experience.
- 💳 **Online Payment**: **Stripe** integration (developer mode) for transactions.
- 🔍 **Automated Scraping**: Collecting manga metadata to populate the database.

#### Tech Stack
MangaFlow is built on a robust and efficient architecture:
- 🖥️ **Backend**: *PHP* with an **MVC** architecture.
- ⚡ **Frontend**: *Vanilla JavaScript* for dynamic interactions.
- 🗄️ **Database**: *MySQL* for storing manga and orders.
- 🎨 **Design & Styling**: *SCSS* for a clean and modern visual appearance.
- 🔗 **Communication**: *AJAX* for seamless client-server exchanges.
- 💳 **Payment**: *Stripe* for online transaction management.
- 🤖 **Automation**: A **scraper** designed to collect and integrate manga data automatically.
