#### Présentation du Projet
Application web multijoueur temps réel inspirée du Loup-Garou, déployée en production (SAE de M1, équipe de 5, janvier à juin 2025). J'ai été Project Manager et chef d'équipe, contributeur à l'architecture globale et lead du développement frontend.

#### Architecture
Microservices (game-engine, game-discovery, chat, gateway, game-history, admin, bot) avec deux interfaces : **GameUI** (React) pour les joueurs et **AdminUI** (Angular) pour les administrateurs. Communication REST, WebSockets et SSE, sécurité JWT.

#### Ma contribution
- 📋 Management global : cadrage, coordination, suivi des sprints.
- 🎮 GameUI : page principale, compte, lobby et discovery, écran de jeu, historique.
- ⚙️ Service Game Discovery (backend) et GitHub Actions de la chaîne backend.

#### Stack Technologique
Spring Boot, React, Angular, Eureka, Docker / Docker Compose, GitHub Actions, SonarQube, Nginx, Maven. Bases polyglottes : PostgreSQL, MongoDB, Neo4j, Redis, Cassandra.
