#### Présentation du Projet

Saexpress est un annuaire informatique basé sur *Active Directory*, développé en trois mois par une équipe de quatre
étudiants dans le cadre d’un projet d’étude à l’IUT Informatique. L’objectif était de concevoir une application
permettant la gestion et la recherche d’utilisateurs à partir d’un serveur Windows hébergeant *Active Directory*.

Pour la démo, l’implémentation réelle d’Active Directory et du backend a été remplacée par des *mocks*, seule
l’application *React* étant déployée.

#### Concept de l’Application

L’application permet aux utilisateurs de se connecter et de rechercher des personnes enregistrées dans l’annuaire grâce
à un moteur de recherche efficace et intuitif.

#### Fonctionnalités Principales

- 🔑 **Authentification sécurisée** : Système de connexion basé sur *JWT*.
- 🔍 **Recherche avancée** : Interface permettant de retrouver facilement des utilisateurs.
- 🖥️ **Annuaire centralisé** : Gestion des utilisateurs à partir d’*Active Directory* (mocké pour la démo).

#### Stack Technologique

L’application repose sur une architecture robuste et moderne :

- 🖥️ **Backend** : *Java* avec *Spring* pour la gestion des utilisateurs et des connexions.
- 🌐 **Frontend** : *React* pour une interface réactive et fluide.
- 🎨 **Stylisation** : *SCSS* pour un design épuré et modulable.
- 🔄 **Communication** : API sécurisée avec *JWT* pour l’authentification.
- ⚙️ **Déploiement** : Seule l’application *React* est en ligne, le backend et *Active Directory* étant simulés via des
  *mocks*.
